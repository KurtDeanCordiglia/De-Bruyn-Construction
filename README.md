# De Bruyn Developments & Projects — Website

One-page website for De Bruyn Developments & Projects, a Cape Town building contractor.

**Services:** Building · Renovating · Painting · Maintenance · Waterproofing · Tiling
**Contact:** 083 424 4263 · debruyndevelopments@gmail.com

## Tech
- A single static `index.html` (HTML, CSS and vanilla JS inline)
- Google Fonts: Archivo, Instrument Sans, JetBrains Mono
- No build step. Open `index.html` in a browser to preview.

## Hosting
Deployed with GitHub Pages from the `main` branch root.
